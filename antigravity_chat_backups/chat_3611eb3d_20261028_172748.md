### Method 2: Create a Local Proxy Server on Your Machine

If Nanotron AI running in your terminal requires a local HTTP address (e.g. `http://localhost:8000` or an Ollama/OpenAI emulator):

We can create a lightweight FastAPI proxy inside your workspace at [`nanotron_bridge/server.py`](file:///Users/ishanjanwa/Documents/Newton%20Hecktober%20Hackathone/nanotron_bridge/server.py):

```python
# nanotron_bridge/server.py
from fastapi import FastAPI, Request
import google.genai as genai
import os

app = FastAPI()
client = genai.Client(api_key=os.environ.get("GEMINI_API_KEY"))

@app.post("/v1/chat/completions")
async def chat_completions(req: Request):
    data = await req.json()
    messages = data.get("messages", [])
    prompt = messages[-1]["content"] if messages else ""
    
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt
    )
    
    return {
        "choices": [{
            "message": {
                "role": "assistant",
                "content": response.text
            }
        }]
    }

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="127.0.0.1", port=8000)
```

Run it with:
```bash
python3 nanotron_bridge/server.py
```
Then point Nanotron AI to:
- **Base URL**: `http://127.0.0.1:8000/v1`
- **API Key**: `not-needed`
